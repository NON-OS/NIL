# Keyboard shortcuts

Press `?` anywhere in Nil to see the main shortcuts. Shortcuts don't fire while you're typing in a text box.

## Anywhere

| Keys | What it does |
|---|---|
| `C` or `N` | New task |
| `⌘K` (Mac) or `Ctrl+K` | Search and commands; in chat, jump to a conversation |
| `/` | Search |
| `?` | Show the shortcuts |
| `Esc` | Close the open panel or dialog |

## Jump to a page

Press `G`, then the second key, within about a second.

| Keys | Page |
|---|---|
| `G` `H` | My work |
| `G` `I` | Inbox |
| `G` `K` | Chat |
| `G` `B` | Board |
| `G` `L` | All tasks |
| `G` `C` | Calendar |
| `G` `D` | Docs |
| `G` `G` | Goals |
| `G` `S` | Insights |
| `G` `M` | Time |
| `G` `N` | Bounties |
| `G` `V` | Votes |
| `G` `P` | Proof of work |
| `G` `T` | Settings |

## Lists

| Keys | What it does |
|---|---|
| `Enter` | Open the task that has focus |
| `X` | Select the task that has focus |
| `Shift` and click | Select a range of tasks |
| `Esc` | Clear the selection |

## Board

| Keys | What it does |
|---|---|
| `Space` | Pick up the card that has focus, or drop it |
| Arrow keys | Move the card you picked up |
| `Esc` | Put the card back where it was |

## Writing

| Keys | What it does |
|---|---|
| `Enter` | Create the task, in the new task box |
| `⌘ Enter` (Mac) or `Ctrl+Enter` | Send a comment, or save a description |
| `@` | Mention a teammate in a comment |
| `Esc` | Stop editing a description without saving |

## Search box

| Keys | What it does |
|---|---|
| Up and down arrows | Move through the results |
| `Enter` | Open the highlighted result |
| `Esc` | Close the search |

## Chat

| Keys | What it does |
|---|---|
| `Enter` | Send. `Shift+Enter` starts a new line |
| `@` | Mention someone in the conversation |
| `⌘K` (Mac) or `Ctrl+K` | Jump to a conversation by name |
| `Alt+↑` and `Alt+↓` | The conversation above or below; with `Shift`, the next unread one |
| `↑` in an empty box | Edit your last message |
| `↑`, `↓`, `Home` and `End` in the messages | Move between messages |
| `E` and `R` | Edit the message that has focus, if it's yours, or reply to it in a thread |
| `Esc` | Back to writing, or close the thread |
