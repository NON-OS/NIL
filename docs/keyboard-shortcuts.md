# Keyboard shortcuts

Press `?` anywhere in Nil to see the main shortcuts. Shortcuts don't fire while you're typing in a text box.

## Anywhere

| Keys | What it does |
|---|---|
| `C` or `N` | New task |
| `⌘K` (Mac) or `Ctrl+K` | Search and commands. In chat it jumps to a conversation, and in a doc's text it adds a link |
| `/` | Search |
| `?` | Show the shortcuts |
| `Esc` | Close the open panel or dialog |

## Jump to a page

Press `G`, then the second key, within about a second.

| Keys | Page |
|---|---|
| `G` `H` | My work |
| `G` `I` | Inbox |
| `G` `K` | Chat |
| `G` `B` | Board |
| `G` `L` | All tasks |
| `G` `C` | Calendar |
| `G` `D` | Docs |
| `G` `F` | Files |
| `G` `A` | Calls |
| `G` `G` | Goals |
| `G` `S` | Insights |
| `G` `M` | Time |
| `G` `N` | Bounties |
| `G` `V` | Votes |
| `G` `P` | Proof of work |
| `G` `T` | Settings |

## In a call

| Keys | What it does |
|---|---|
| `⌘D` (Mac) or `Ctrl+D` | Mute or unmute, anywhere in Nil |
| `⌘E` (Mac) or `Ctrl+E` | Camera on or off, anywhere in Nil |
| `M` | Mute or unmute, on the call screen |
| `V` | Camera on or off, on the call screen |
| `S` | Share your screen, or stop |
| `L` | Grid or speaker layout |
| `P` | Picture in picture |
| `Esc` | Minimize the call |

## Lists

| Keys | What it does |
|---|---|
| `Enter` | Open the task that has focus |
| `X` | Select the task that has focus |
| `Shift` and click | Select a range of tasks |
| `Esc` | Clear the selection |

## Board

| Keys | What it does |
|---|---|
| `Space` | Pick up the card that has focus, or drop it |
| Arrow keys | Move the card you picked up |
| `Esc` | Put the card back where it was |

## Files

| Keys | What it does |
|---|---|
| Arrow keys, `Home`, `End` | Move between the files and folders in a folder |
| `Enter` | Open the folder, or preview the file, that has focus |
| `F2` | Rename it |
| `Delete` or `⌘ Backspace` (Mac) | Delete it, after asking |
| `Backspace` | Go up one folder |
| `⌘V` (Mac) or `Ctrl+V` | Upload the files you copied |
| Left and right arrows | In a preview, show the previous or next file |
| `+`, `-` and `0` | In a preview, zoom an image or PDF in or out, or fit it again |
| `Page Up`, `Page Down` | In a PDF preview, turn the page |

## Writing

| Keys | What it does |
|---|---|
| `Enter` | Create the task, in the new task box |
| `⌘ Enter` (Mac) or `Ctrl+Enter` | Send a comment, or save a description |
| `@` | Mention a teammate in a comment |
| `Esc` | Stop editing a description without saving |

## Search box

| Keys | What it does |
|---|---|
| Up and down arrows | Move through the results |
| `Enter` | Open the highlighted result |
| `Esc` | Close the search |

| `⌘K` (Mac) or `Ctrl+K` | Search and commands. In chat it jumps to a conversation, and in a doc's text it adds a link |
