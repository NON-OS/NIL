# Keyboard shortcuts

Press `?` anywhere in Nil to see the main shortcuts. Shortcuts don't fire while you're typing in a text box.

## Anywhere

| Keys | What it does |
|---|---|
| `C` or `N` | New task |
| `⌘K` (Mac) or `Ctrl+K` | Search and commands. In a doc's text it adds a link instead |
| `/` | Search |
| `?` | Show the shortcuts |
| `Esc` | Close the open panel or dialog |

## Jump to a page

Press `G`, then the second key, within about a second.

| Keys | Page |
|---|---|
| `G` `H` | My work |
| `G` `I` | Inbox |
| `G` `B` | Board |
| `G` `L` | All tasks |
| `G` `C` | Calendar |
| `G` `D` | Docs |
| `G` `G` | Goals |
| `G` `S` | Insights |
| `G` `M` | Time |
| `G` `N` | Bounties |
| `G` `V` | Votes |
| `G` `P` | Proof of work |
| `G` `T` | Settings |

## Lists

| Keys | What it does |
|---|---|
| `Enter` | Open the task that has focus |
| `X` | Select the task that has focus |
| `Shift` and click | Select a range of tasks |
| `Esc` | Clear the selection |

## Board

| Keys | What it does |
|---|---|
| `Space` | Pick up the card that has focus, or drop it |
| Arrow keys | Move the card you picked up |
| `Esc` | Put the card back where it was |

## Writing

| Keys | What it does |
|---|---|
| `Enter` | Create the task, in the new task box |
| `⌘ Enter` (Mac) or `Ctrl+Enter` | Send a comment, or save a description |
| `@` | Mention a teammate in a comment |
| `Esc` | Stop editing a description without saving |

## Search box

| Keys | What it does |
|---|---|
| Up and down arrows | Move through the results |
| `Enter` | Open the highlighted result |
| `Esc` | Close the search |

## Docs

| Keys | What it does |
|---|---|
| `/` | Add a block: a heading, list, to-do list, table, quote, code block or divider |
| `@` | Mention a teammate |
| `⌘B`, `⌘I`, `⌘U` (Mac) or `Ctrl+B`, `Ctrl+I`, `Ctrl+U` | Bold, italic, underline |
| `⌘⇧S` (Mac) or `Ctrl+Shift+S` | Strikethrough |
| `⌘E` (Mac) or `Ctrl+E` | Inline code |
| `⌘⇧H` (Mac) or `Ctrl+Shift+H` | Highlight |
| `⌘K` (Mac) or `Ctrl+K` | Add or change a link |
| `⌘⌥M` (Mac) or `Ctrl+Alt+M` | Comment on the selected words |
| `⌘Z` and `⌘⇧Z` (Mac) or `Ctrl+Z` and `Ctrl+Shift+Z` | Undo and redo your own changes |
| `#` then a space, `-` then a space, `[ ]` then a space | Heading, bulleted list, to-do item, as you type |
| `Tab` and `Shift+Tab` | Indent and outdent a list item |
