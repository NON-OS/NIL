# Atlas 2.0 launch plan

Atlas 2.0 is the redesigned wallet: a new onboarding, hardware wallet pairing and a faster home screen. We ship to the App Store and Google Play on **Tuesday 8 December**, with the beta group a week earlier.

## Goals

- 500 beta testers before the public release (412 today)
- Crash-free sessions above 99.5% in the last beta week
- Onboarding finished by 80% of new installs, up from 61%

## Timeline

| Week | What ships | Owner |
| --- | --- | --- |
| 2 November | Feature freeze, TestFlight build | Cleo |
| 9 November | Accessibility pass, release notes | Ben, Dev |
| 16 November | Security review signed off | Ada |
| 1 December | Beta group gets the release candidate | Cleo |
| 8 December | Public release | Everyone |

## Risks

1. **Bluetooth pairing on older Android phones.** Cleo is testing on eight devices. If it slips, pairing ships behind a setting.
2. **App Store review time.** We submit five days early and keep the old version ready.
3. **Translation quality.** Spanish and Portuguese go to two native speakers from the beta group.
